## Why it matters

You can't fix what you can't see. Funnels reveal exactly where users drop off, turning vague problems ("conversion is low") into specific fixes ("step 3 kills 67% of users").

## Template

**Core Funnel Structure:**
```
Acquisition ’ Activation ’ Revenue ’ Retention ’ Referral

Example E-commerce:
Visit Site (100%)
  “
View Product (45%)
  “
Add to Cart (12%)
  “
Begin Checkout (8%)
  “
Complete Purchase (3%)
```

**Analysis Framework:**
- **Drop-off rates** between each step
- **Time between steps** (velocity)
- **Segmentation** by source, device, user type
- **Conversion rate** end-to-end

## Common mistakes

1. **Too many steps** - Include only critical actions
2. **Wrong order** - Users don't always follow your ideal path
3. **No segmentation** - Averaging hides insights
4. **Ignoring time** - Not all conversions happen immediately

## Example output

**Dropbox's Referral Funnel:**
```
Sees Referral Prompt (100%)
    “ 25% click
Visits Referral Page (25%)
    “ 60% start
Enters Friend's Email (15%)
    “ 80% send
Sends Invitation (12%)
    “ 35% accept
Friend Signs Up (4.2%)
    “ 90% qualify
Both Get Reward (3.8%)
```

Identified: Email entry was biggest friction. Solution: Social sharing options increased completion 2.5x.
