## Why it matters

Bad data kills companies slowly. You make wrong decisions, lose trust, and waste months debating numbers instead of growing. Good data quality = faster decisions.

## Template

**Quality Scorecard:**
```
Completeness: [% of required fields populated]
Accuracy: [% matching source of truth]
Consistency: [% following naming conventions]
Timeliness: [% updated within SLA]
Uniqueness: [% without duplicates]
```

**Monitoring Setup:**
- Volume checks (±20% threshold)
- Freshness alerts (<24hr delay)
- Schema validation (type/format)
- Business logic tests
- Anomaly detection

## Common mistakes

1. **No ownership** - "Someone else will fix it"
2. **Manual checks only** - Humans miss patterns
3. **Fixing symptoms** - Not addressing root causes
4. **No documentation** - Same issues repeatedly
