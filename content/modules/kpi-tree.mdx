## Why it matters

Without a KPI tree, teams track vanity metrics that don't drive business outcomes. This framework connects every metric to your ultimate goal, creating accountability and focus.

## Template

```
North Star Metric
├── Input Metric 1
│   ├── Leading Indicator 1.1
│   └── Leading Indicator 1.2
└── Input Metric 2
    ├── Leading Indicator 2.1
    └── Leading Indicator 2.2
```

Key components:
- **North Star**: Single metric that captures value delivered
- **Input Metrics**: 3-5 drivers that directly influence North Star
- **Leading Indicators**: Early signals that predict input metrics

## Common mistakes

1. **Too many metrics** - More than 5 input metrics dilutes focus
2. **Missing connections** - Each metric must mathematically relate to parent
3. **Lagging only** - No early warning signals for course correction
4. **Team misalignment** - Metrics not mapped to team ownership

## Example output

**Spotify's KPI Tree:**
```
Monthly Active Users (MAU)
├── New User Acquisition
│   ├── App Store Rankings
│   └── Viral Coefficient
├── User Retention
│   ├── Day 1 Retention
│   └── Weekly Active %
└── Resurrection Rate
    ├── Push Notification CTR
    └── Email Re-engagement
```

Each team owns specific branches, creating clear accountability.
