## Why it matters
Dashboards are the operating interface of Growth OS. If everyone looks at different charts, you don't have a shared language — you have opinions.

## Template
### Standard pack (recommended)
1) **Acquisition → Signup**
- conversion, drop-off, source breakdown

2) **Activation**
- activation rate, TTV, activation funnel

3) **Onboarding steps**
- completion per step, time per step

4) **Retention (cohorts)**
- W1/W4 (user + workspace), returning rate

5) **Feature adoption**
- adoption by plan/role, top key actions

6) **Trial → Paid**
- trial started → checkout started → subscription started

### Rules
- Each dashboard has an owner and metric definitions.
- Each chart answers a decision ("what will we do if this moves?").

## Common mistakes
- Too many charts, no decisions.
- No segmentation.
- Undefined metrics (counting something different than you think).

## Example output
One "North Star" board + one "Activation" board for weekly review.
